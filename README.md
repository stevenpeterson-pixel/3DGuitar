# Concert Acoustic — a playable 3D guitar

**Play it in a browser:** https://stevenpeterson-pixel.github.io/3DGuitar/

A guitar you play with a mouse, keyboard or touch screen, or let play itself from a library of public-domain songs. Nothing is a recording: every string is simulated as it vibrates (extended Karplus-Strong synthesis), then shaped by a model of the body or of a pickup and amplifier.

- 18 instruments: seven acoustic guitars, bass, ukulele, banjo, mandolin and seven electric guitars
- Effects: amplifier, drive, compressor, wah, chorus, tremolo, echo and four reverbs
- 39 self-playing songs, a pop-out lyrics window (you supply the words), and a built-in user's manual (F1)
- A 3D guitar you can flip, zoom and place in a dark studio or a living room

## On an iPad

Open the link above in Safari, tap Share, then **Add to Home Screen**. After the first visit it works offline. Hold the iPad sideways.

## What is in this repository

| Path | What it is |
|---|---|
| `index.html` | The whole instrument: sound engine, 3D view, song player, manual |
| `lib/` | three.js, the converted song scores, and score credits (`SOURCES.txt`) |
| `docs/` | The website GitHub Pages serves. Generated by `build-web.ps1`; do not edit by hand |
| `build-web.ps1` | Rebuilds `docs/` (icons, manifest, offline cache) from `index.html` and `lib/` |
| `shell/` | The Windows desktop app: a .NET 10 + WebView2 window around the same page |

## Updating the website

```powershell
pwsh ./build-web.ps1
git add -A
git commit -m "Update"
git push
```

## Building the Windows app

```powershell
dotnet publish shell -c Release -o publish
```

This produces a single self-contained `publish/AcousticGuitar.exe`. It needs the Microsoft Edge WebView2 Runtime, which ships with Windows 11.
